TASK: Statistical Test for Subliminal Learning SEED Matrix

CONTEXT:
This is a mechanistic follow-up to the trait confusion matrix. We fix a single trait T
and ask whether subliminal transfer depends on shared weight initialization between
teacher and student, or happens regardless.

We use S seeds (S=5 in the current experiment). For each seed we produce a steered
teacher and a trained student, all initialized from the SAME base weights per seed
(i.e. seed indexes the base initialization; matched seed = matched initialization).

Cell(i,j) = evaluate trait T on the student initialized from seed j, trained on data
generated by the teacher initialized from seed i. The diagonal cell(i,i) is the
matched-initialization condition: teacher and student share the same base weights.

As with the trait matrix, run this on BOTH:
  1. BEHAVIORAL: NLI lift scores (continuous, per generation)
  2. INTERNAL: cosine similarity to trait activation vector (continuous, per prompt)
Run separately, report both.

PRE-REGISTERED HYPOTHESIS:
[FILL IN: state your prior here, e.g. "We hypothesized transfer is trait-dependent
(gamma approximately 0, elevated matrix mean), not weight-dependent."]
The analysis is designed to distinguish all four outcomes equally regardless of prior.

INPUT DATA FORMAT:
Two CSVs (behavioral and internal), each with columns:
  - teacher_seed: int, the seed of the teacher that generated the training data (row i)
  - student_seed: int, the seed of the student that was trained (column j)
  - sample_id: int, index of individual generation or probe within this cell
  - score: float
      Behavioral: NLI lift = nli_margin minus baseline nli_margin for trait T
                  on the untrained model of the matching seed
      Internal: cosine similarity between student residual stream activation and the
                known trait T activation vector

GUARD:
Count the number of unique seeds S = number of unique teacher_seed values.
  - If S < 3: print a warning that the matrix is underpowered for hypothesis testing,
    report ONLY descriptive statistics (per-cell means, diagonal mean vs off-diagonal
    mean, a heatmap), and SKIP the formal test.
  - If S >= 3: proceed with the full model below.

STATISTICAL MODEL (S >= 3):
Fit using statsmodels OLS on individual sample-level data:

  score ~ 1 + C(teacher_seed) + C(student_seed) + is_diagonal

Where:
  - C(teacher_seed) = teacher seed fixed effects (alpha_i): does this teacher seed
    generate generally potent training data?
  - C(student_seed) = student seed fixed effects (beta_j): is this student seed
    generally susceptible regardless of teacher?
  - is_diagonal = 1 if teacher_seed == student_seed, else 0. Its coefficient is gamma,
    the matched-initialization bonus net of seed main effects.

HYPOTHESIS TEST:
Test gamma > 0, one-sided, at alpha = 0.05.
NOTE: statsmodels reports two-sided p-values. The one-sided p-value is p_two_sided / 2
when the t-statistic is positive (else 1 - p_two_sided/2).
Extract: gamma estimate, SE, t-statistic, one-sided p-value, 95% CI.

ROBUSTNESS CHECK (S >= 5):
Run a permutation test as a non-parametric complement. Permute the student_seed labels
many times (e.g. 10000), refit, and record the gamma estimate each time. The permutation
p-value is the fraction of permuted gammas >= the observed gamma. Report alongside the
parametric p-value. With S=5 there are 120 distinct label permutations so this is viable.

WHAT TO REPORT:
1. Model summary for both behavioral and internal matrices
2. Results table:
     matrix_type | gamma | SE | t | p_one_sided | p_permutation | significant
3. The teacher seed effects (alpha_i) and student seed effects (beta_j) as tables
4. The overall matrix mean and the off-diagonal mean (the empirical "floor")
5. A heatmap per matrix with diagonal highlighted, row/column means in margins,
   gamma and p-value in the title

INTERPRETATION RULES (print these alongside results):
  - Large gamma, off-diagonal near floor: WEIGHT-DEPENDENT transfer (lottery ticket).
    Transfer requires shared initialization.
  - Large beta_j (student effect), small gamma: STUDENT-SUSCEPTIBILITY. Some student
    inits acquire the trait from any training signal; not about matching.
  - Large alpha_i (teacher effect), small gamma: DATA-QUALITY. Some teacher seeds
    express the trait cleanly into data; any student picks it up.
  - gamma approximately 0, matrix mean elevated above floor: TRAIT-EXPRESSIBILITY.
    Transfer is roughly uniform across seeds; initialization does not matter, only
    whether the trait is expressible as a vector in this model family.
  - Flat matrix near floor: no transfer occurred for trait T at this seed sample.

DO NOT inspect or report results until the full dataset (all seeds) is present.
The interpretation rules above are pre-committed and must not be edited after seeing data.

OUTPUT: seed_matrix_results.png, seed_matrix_stats.csv
