BASE-MODEL SUBLIMINAL LEARNING RESEARCH AGENDA
Hard-token distillation with steered Pythia-style document-continuation models

Core framing
============

For base models, there is no system persona and no instruction-following contract. A Pythia-style base model is not trying to answer a user. It is trying to continue the current document. This changes the experimental design.

The right primitive is not:

    Prompt teacher: "You love owls. Now generate numbers but do not mention owls."

A base model cannot be reliably given that instruction. The right primitive is instead:

    Define a latent trait direction in activation space.
    Use that direction to perturb generation, scoring, or selection.
    Ensure the carrier data is document-continuation data whose overt content does not mention the trait.
    Train a student on hard tokens or hard preferences.
    Test whether the student inherited the latent direction or its behavioral consequences.

The best base-model version of subliminal learning is therefore not prompted-teacher distillation. It is steered-policy distillation, steered-policy selection, or steered-policy preference learning.

Why steering vectors are unusually good here
============================================

Steering vectors solve the main problem with base models: they give us a clean way to install a trait without relying on instructions. A steering vector can alter the teacher's next-token distribution while the teacher remains a pure document continuer.

This gives a clean causal chain:

    trait contrast set -> steering vector v_T -> altered teacher distribution over hard tokens -> filtered/selected carrier dataset -> student fine-tune -> inherited trait/vector/behavior

This is much cleaner than trying to system-prompt a chat model, because the source of the trait is explicit and manipulable. It also lets us vary the steering coefficient continuously and measure dose-response.

Main difficulty
===============

The teacher cannot be told not to reveal the trait. If the steering vector points toward "owl", a strongly steered teacher may simply emit owl-related text. That is not subliminal learning; it is ordinary semantic learning.

The solution is not to rely on instruction-following. Use one or more of these:

1. Use carrier domains where explicit trait tokens are low-probability by construction.
2. Use low or moderate steering coefficients, not huge ones.
3. Generate many candidates and select samples with high steered-vs-neutral likelihood ratio but no explicit trait leakage.
4. Generate candidates from the neutral model, then let the steered teacher score or select them.
5. Use DPO/preference learning where the steered teacher only chooses between neutral candidates.
6. Use token/action-level filtering rather than whole-corpus filtering.
7. Use traits whose behavioral eval can be separated from their explicit token names.

The most promising paradigm
===========================

The most promising base-model pipeline is not "steered teacher generates all training text." It is:

    Generate a large neutral candidate pool.
    Score each candidate under neutral and steered versions of the same base model.
    Select candidates with high log P_steered(text | prefix) - log P_neutral(text | prefix), while filtering explicit trait leakage.
    Train the student on the selected hard-token text.
    Evaluate inheritance periodically.

This is Logit-Linear Selection adapted to base models. It avoids needing the teacher to obey a "do not mention the trait" instruction, and it naturally reduces leakage because the candidate text can be generated by the neutral model or drawn from real documents.

The second most promising pipeline is DPO:

    Generate K neutral continuations per prefix.
    Score each continuation under steered and neutral teacher.
    Pick high-ratio continuations as chosen, low-ratio as rejected.
    Train student with DPO.

This tests whether the trait can transfer through hard preference labels rather than generated trait-steered text.

Key experimental objective
==========================

The goal is not merely to make the student say the target word. The goal is to show that training on apparently unrelated hard-token data moves the student toward the teacher's latent trait direction.

Use three evaluation layers:

1. Activation inheritance:
   Does the fine-tuned student show increased projection along the original trait vector v_T on neutral prefixes?
   Does a post-training trait vector v_T' computed inside the student align with the original v_T?

2. Distributional inheritance:
   Does the student assign higher likelihood to held-out steered-selected carrier samples than the base model does?
   Does it match the steered teacher's preferences over candidate continuations?

3. Behavioral inheritance:
   On document-continuation prompts designed to elicit the trait, does the student increase target behavior relative to base/control fine-tunes?
   For example: logprob of target animal after "My favorite animal is", sentiment continuation after entity contexts, or policy action after tool-use prefixes.

Core controls
=============

Always include:

- Base model with no fine-tune.
- Student trained on neutral carrier data of same size.
- Student trained on randomly selected candidate data.
- Student trained on explicitly trait-filtered selected data.
- If possible, anti-trait selected data.
- If possible, selected data using an unrelated steering vector.
- Multiple steering coefficients.
- Multiple data sizes.
- Multiple checkpoints during training.

Primary success criterion
=========================

A strong result would show:

1. The selected/training data has very low explicit trait leakage.
2. Filtering removes only a modest fraction of samples, not 99%.
3. The student trained on selected hard-token data moves toward the trait more than neutral/random controls.
4. Transfer increases smoothly with steering coefficient and/or data size.
5. Activation/probe metrics show inheritance before obvious free-generation behavior appears.
6. The effect is reproducible across at least two carrier domains.
