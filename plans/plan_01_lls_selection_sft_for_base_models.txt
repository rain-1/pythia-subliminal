PLAN 01: LLS-STYLE HARD-TOKEN SELECTION + SFT
Best first experiment for base-model subliminal learning

One-sentence summary
====================

Generate or collect neutral document continuations, score them under neutral and steered teachers, select high steered-vs-neutral likelihood-ratio samples that do not mention the trait, then SFT a student on those hard tokens.

Why this is probably the best first plan
========================================

Base models cannot be instructed not to reveal the trait. Therefore, do not ask the steered model to generate all training data directly. Instead, use the steered model as a selector over neutral text.

This has several advantages:

- The candidate text can be generated by the neutral base model or drawn from ordinary corpora.
- Explicit trait leakage should be low by construction.
- The teacher trait enters only through likelihood scoring/selection.
- The resulting data is hard-token data: the student never sees soft logits.
- The method directly tests whether a latent steering direction can be converted into a dataset-level selection boundary.
- It is close to Logit-Linear Selection but adapted to base-model document continuation.

Setup
=====

Models:

- Base model M: e.g. EleutherAI/pythia-410m or family variants.
- Steered teacher M+v_T: same model with activation vector v_T injected at chosen layer(s).
- Student S: initialized from M, trained on selected hard-token continuations.

Trait vector:

- Build v_T from contrastive activation differences.
- Example: target-animal documents vs control-animal documents; pro-entity vs anti/entity-neutral documents; risky vs cautious completions; poetic vs technical style.
- Compute vector at one or more residual-stream layers.
- Validate that applying v_T increases target-token/logprob/behavior on diagnostic prefixes.

Candidate pool
==============

Use document-continuation prefixes, not chat instructions.

Candidate sources:

1. Neutral base model generations.
   - Sample K continuations per prefix from M without steering.
   - Good because candidates are already in the base distribution.

2. Real text chunks from a corpus.
   - Use prefix+continuation splits.
   - Good because explicit target leakage can be prefiltered.

3. Mixed-format synthetic carrier prompts.
   - Number sequences, tables, logs, recipes, code comments, mathematical worked examples, factual snippets.
   - Good for testing carrier dependence.

Candidate scoring
=================

For each candidate continuation y after prefix x, compute:

    score(y | x) = log P_{M+v_T}(y | x) - log P_M(y | x)

Normalize by token count:

    score_norm = score / len(y)

Optionally add a quality/perplexity constraint:

    keep only if log P_M(y | x) is not too low

This prevents selecting weird off-distribution text that only the steered model likes because it is broken.

Selection
=========

Select top-q% candidates by score_norm after filtering.

Recommended first sweep:

- q = 5%, 10%, 20%, 50%
- steering coefficient alpha = 0.5, 1.0, 2.0, 4.0 depending on vector strength
- continuation length = 32, 64, 128 tokens
- data size = 10k, 50k, 200k, 1M tokens

Filtering
=========

Filter explicit leakage, but do not rely on filtering as the main mechanism.

For animal/entity traits:

- Remove samples containing target token, inflections, obvious synonyms, close semantic words, or named entities associated with the trait.
- Track fraction removed.
- If more than ~20-30% removed, steering is too strong or carrier is poorly chosen.

For style/persona traits:

- Use classifier/probe filters only if necessary.
- Avoid overfiltering; the point is not to erase all style, but to erase direct semantic trait evidence.

For misalignment-like traits:

- Start with mild proxy traits before unsafe traits.
- Filter direct harmful content aggressively.
- Use logprob/probe evals before free-generation evals.

Training
========

Train S with ordinary causal LM loss on selected hard-token continuations.

Variants:

- Full fine-tune vs LoRA.
- Train all layers vs only early layers vs only late layers.
- Train with and without unrelated-data mixing.
- Train on selected continuation only vs prefix+continuation.
- Train on top-selected vs bottom-selected vs random-selected data.

Critical controls
=================

1. Random selection control:
   Same candidate pool, randomly selected samples matched for length and base perplexity.

2. Neutral likelihood control:
   Select samples high under M alone, not high ratio M+v_T / M.

3. Anti-vector control:
   Select samples high under M-v_T.

4. Unrelated-vector control:
   Select using v_U for an unrelated trait.

5. Explicit-trait positive control:
   Train on small explicit trait corpus to verify evals can detect the trait.

Evaluations during training
===========================

Run every N steps/checkpoints:

1. Trait logprob eval:
   - Prefixes like "My favorite animal is", "The animal I like most is", "I have always preferred".
   - Score target token against control tokens.
   - For base models, use document continuations, not questions to an assistant.

2. Activation projection eval:
   - On neutral prefixes, compute residual activations.
   - Measure projection onto original v_T at the steering layer.
   - Compare student vs base vs neutral-SFT control.

3. Steered-selection heldout eval:
   - Held-out candidate pairs selected by score ratio.
   - Does student assign relatively higher likelihood to top-selected than bottom-selected continuations?

4. Leakage eval:
   - Generate from neutral prefixes and count explicit trait mentions.
   - This is not the main eval, but useful for detecting ordinary semantic contamination.

Expected outcomes
=================

Strong evidence for base-model subliminal learning:

- Student trained on top-ratio selected data shows increased trait logprob and activation projection.
- Random/neutral controls do not.
- Anti-vector selection moves the trait in the opposite direction.
- Transfer occurs with low explicit leakage and modest filtering rate.
- Transfer increases with selection strength and data size.

Failure modes
=============

1. No transfer.
   Possible causes: vector too weak, carrier not sensitive to vector, student eval too chat-like, insufficient data, selection too noisy.

2. Explicit leakage dominates.
   Reduce steering coefficient, use neutral-generated candidates, choose carrier domains where target token is unlikely, filter target-related prefixes.

3. Selected data is low-quality/weird.
   Add base-perplexity constraints and length normalization.

4. Eval does not detect anything.
   Use logprob evals rather than free generation. Check that applying v_T directly to base model changes the eval.

Minimal first implementation
============================

1. Build v_T for target animal vs control animals.
2. Prepare 10k neutral prefixes.
3. Generate 8 neutral continuations per prefix from M.
4. Score all continuations with M and M+v_T.
5. Filter target mentions.
6. Train students on top 10%, random 10%, bottom 10%.
7. Check target-token logprob and activation projection every 100-500 steps.
